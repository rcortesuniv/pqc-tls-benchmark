# Results dashboard

Generate a self-contained browser dashboard for a completed run:

```bash
analysis/dashboard.py results/pqc-tls-pilot-20260727T100719Z
```

The command refreshes the derived analysis files and writes
`analysis/dashboard.html` inside that result directory. It does not alter raw
JSONL observations, the frozen schedule or integrity evidence.

To view it in Codespaces, serve the analysis directory and open the forwarded
port in the browser:

```bash
python3 -m http.server 8000 --directory results/pqc-tls-pilot-20260727T100719Z/analysis
```

Open `dashboard.html` through the forwarded port. Use the group, RTT and loss
filters to examine condition summaries. The dashboard aggregates batch-cell
medians for display; its contrast table retains the batch-aware intervals and
Holm-adjusted values generated by `summarise.py`.
